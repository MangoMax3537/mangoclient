# Rust port spec (derived from Electron 1.3.4, `src/main/*.js`)

Condensed from a read of every main-process module. The legacy source stays the source of truth until deleted; when this file and the code disagree, trust the code and fix this file.

## Data layout (must load unchanged)

Root: `$MANGOCLIENT_HOME`, else Win `%APPDATA%\.mangoclient`, mac `~/Library/Application Support/mangoclient`, Linux `~/.mangoclient`.
Subdirs: `versions, libraries, assets/{indexes,objects,log_configs,virtual,resources}, natives, runtimes, instances/<uuid>, cache, covers/<uuid>.png, logs`.
Files: `config.json`, `accounts.json` (holds BOTH `accounts` and `profiles`), `install.json {id,created}`, `stats.json {version:1,sessions:[{p,s,ms}]}` (cap 4000, ignore <30s), `server-icons.json`, `launcher_profiles*.json`.

- **config.json**: atomic write, 0600, `.bak` rotation, per-key validation (invalid key falls back to default). language de|en (default `de`), theme `mango`, ram 1024..131072 (default half of system RAM, 512 steps, clamp 2048..8192), javaPath, javaArgs, fullscreen, width 640..16384, height 480..16384, keepLauncherOpen, hideOnLaunch, showSnapshots, mangoConfig, performanceMods, sidebarOpen, concurrentDownloads 1..32 (12), performancePreset potato|balanced|quality, selectedProfile, selectedAccount, firstRunDone, telemetry.
- **Profile**: `{id uuid4, name<=128, mcVersion, loader vanilla|fabric|quilt|forge|neoforge, loaderVersion, color, cover(derived), ram, javaArgs, mods[], mangoConfig, session{pid,versionId,startedAt}|null, lastPlayed, playTimeMs, created}`. Mod record `file` is an **absolute path**; duplicating a profile rebases it. Loader must tolerate this or migrate.
- **Account**: `{type microsoft|offline, uuid, name, accessToken, msaRefreshToken, expiresAt, skins[], capes[], encryptedCredentials?}`. Tokens never reach the UI. Public shape: `{uuid,name,type,expiresAt,expired,hasCape}`.
- Persistence: tmp + fsync + rename, previous generation kept as `.bak`, recover from `.bak` when main is corrupt (do not rotate a corrupt main over a good bak). JSON pretty-printed, 2 spaces, trailing newline.
- Migrations: inline `data:image/png` mod icons to `cache/mod-icons/<sha1>.png`; plaintext tokens re-encrypted when a keyring exists; profiles with unsafe mod paths filtered; `cover` repaired from file existence.

## Auth

MSA code flow on `login.live.com`, public client id `00000000402b5328` (env `MANGOCLIENT_MSA_CLIENT_ID`), redirect `https://login.live.com/oauth20_desktop.srf`, scope `service::user.auth.xboxlive.com::MBI_SSL`, `prompt=select_account`. Chain: XBL authenticate (RPS ticket verbatim, RelyingParty `http://auth.xboxlive.com`) -> XSTS (`rp://api.minecraftservices.com/`, RETAIL) -> `login_with_xbox` (`XBL3.0 x=<uhs>;<token>`) -> entitlements (failure ignored) -> profile. 404 on profile = no profile vs not owned. XErr: 2148916233 no Xbox profile, 235 country, 236/237 adult verification, 238 child account. Refresh when <5 min left; no refresh token = `needsRelogin`. Login window is isolated/in-memory with all permissions denied; `error=access_denied` = cancel (returns null).
Offline: name `^[A-Za-z0-9_]{3,16}$`, uuid = MD5("OfflinePlayer:"+name) with v3 + RFC4122 variant bits, hex without dashes, token `"0"`.
**Credential interop**: existing `encryptedCredentials` blobs are Electron safeStorage (Chromium OSCrypt). `keyring` cannot read them. Decision needed: force re-login on first Rust run, or write an OSCrypt reader. Linux `basic_text` backend is treated as insecure: fall back to 0600 plaintext, and keep `credentialsLocked` envelopes intact when the keyring is unavailable.

## Network

UA `MangoClient/1.0.0 (+https://github.com/mangomax/mangoclient)`. `fetchWithRetry`: 5 attempts, 400ms*2^n backoff, 60s timeout, retry 5xx and 429 only. `downloadFile`: skip if valid, `.part-*` temp, reject on content-length mismatch (only when >0) or overrun, verify sha512/sha256/sha1 + size, atomic rename. Integrity cache `cache/integrity-cache.json` (hash,size,mtime,ctime; debounced 250ms; only under root). Bounded-concurrency `pool` preserving order.
Endpoints: Mojang `launchermeta.mojang.com/mc/game/version_manifest_v2.json` (6h cache, offline fallback), `resources.download.minecraft.net`, `libraries.minecraft.net`; Fabric `meta.fabricmc.net/v2`; Quilt `meta.quiltmc.org/v3`; NeoForge `maven.neoforged.net/releases/net/neoforged/neoforge`; Forge `maven.minecraftforge.net/net/minecraftforge/forge`; Adoptium `api.adoptium.net/v3/assets/latest/<major>/hotspot`; Modrinth `api.modrinth.com/v2`; skins `sessionserver.mojang.com` + `api.minecraftservices.com/minecraft/profile/skins`; logs `api.mclo.gs/1/log` (last 25000 lines); telemetry `${MANGO_API_BASE}/v1/launcher`.

## Install and launch

- Version JSON: cache at `versions/<id>/<id>.json`, flatten `inheritsFrom`. Child libraries win over parent for same `group:artifact[:classifier]` (version ignored, prevents duplicate ASM). Rules: last-match-wins, default deny; os.name/arch/version(regex)/features.
- Natives: legacy `natives` classifiers (`${arch}` to 32/64) and `:natives-<os>[-<arch>]`. Prefer exact-arch over un-suffixed; drop foreign OS/arch (else lwjgl.dll is clobbered). `natives-macos-patch` is not an arch. Arch aliases: x64=[x64,x86_64,x86-64,amd64], arm64=[arm64,aarch64], ia32=[x86,x86_32,i386], arm=[arm,arm32]. Extract flat into `natives/<versionId>/` (so/dll/dylib/jnilib only), guarded by `.mangoclient-stamp`, wipe on stamp change.
- Loader without `downloads.client` copies the parent's jar. Library download failures only logged unless invalid; asset failures logged and skipped. Legacy assets (`virtual`/`map_to_resources`) copied.
- Loader ids: `fabric-loader-<lv>-<mc>`, `quilt-loader-...`, `neoforge-<lv>`, `<mc>-forge-<lv>`. Forge/NeoForge: download installer to `cache/`, write `launcher_profiles.json` (+ `_microsoft_store.json`) `{profiles:{},version:3}`, run `java -jar installer --installClient <root>`. No hash for installer jars. NeoForge version prefix from MC (1.21.4 -> `21.4.`).
- Java: probe `java -version` (10s, memoized; 1.8 = 8). Search JAVA_HOME, PATH, `/usr/lib/jvm`, `/usr/java`, `/opt/java`, macOS JVM dir. Managed in `runtimes/<name>`. Order: custom override (error if not runnable or too old) -> managed (exact, else greater) -> system (exact, else smallest newer only if required>=17) -> download Temurin JRE (validate bare filename, sha256+size) to `runtimes/jre-<major>`. Required major from `javaVersion.majorVersion`, else fallback (year-style `NN.` = 25; minor>=20 = 21; >=18 = 17; >=17 = 16; else 8). Prefer `javaw.exe` on Windows.
- **Launch order**: reject if running/detached; sync mods; vanilla auto-switches to Fabric when MangoConfig enabled and a jar exists (Forge/NeoForge/Quilt never switched); run `mangoconfig.ensure` and `performancemods.ensure` in parallel (never throw); background token refresh + seed `options.txt`/`servers.dat`; resolve vanilla JSON, Java, loader, install version; re-resolve Java if merged version needs higher; persist refreshed account; build args; spawn.
- **JVM args order**: `-Xmx<ram>M -Xms<min(ram,1024)>M`, preset (balanced = Aikar G1; potato = SerialGC + TieredStopAtLevel=1; quality = ZGC+ZGenerational), UTF-8 flags, brand flags, `-XstartOnFirstThread` on mac, log4j arg, version jvm args (pre-1.13: `-Djava.library.path`, `-cp`), global then per-profile extra args split on whitespace. Game args: `--fullscreen` or `--width/--height`; quick join `--server/--port` unless `--quickPlayMultiplayer` exists. Variables: `auth_session=token:<tok>:<uuid>`, `user_type` legacy (offline) / msa, `launcher_name MangoClient`, `launcher_version` currently hard-coded `1.0.0`, `auth_xuid` default `0`. Unknown `${x}` left untouched. Env: INST_NAME, INST_ID, INST_DIR.
- **Game outlives the launcher**: spawn detached (setsid / DETACHED_PROCESS|CREATE_NO_WINDOW), stdio to `logs/<slug>-<id8>.log` (truncated per run). Tail by polling 300ms (<=256KB, UTF-8 decoder safe across chunks), parse log4j XML events to `[HH:MM:SS] [thread/LEVEL]: msg`. "Running" = regex (`Setting user:|LWJGL Version|Created:.*minecraft:textures|OpenAL initialized`) or 8s fallback while alive. Persist `session{pid,versionId,startedAt}`; on startup adopt live pids (verify process name contains `java`), poll 10s, refuse launching a detached profile. Flush playtime on exit and before-quit (no double count). On close: flush, stop follower, cache server icon, emit stopped/crashed. `hideOnLaunch` hides at running and re-shows on exit. Do not kill non-java pids when stopping an adopted session (legacy bug: no re-check).

## Content

- Modrinth: in-memory cache (search 5 min, others 15 min, categories 24h, LRU 250, in-flight dedup). Search facets: project_type, loader categories (quilt includes fabric, neoforge includes forge, mods only), versions, categories, open_source. `pickVersion`: newest release by `date_published`, else newest. Primary file or first. Required deps recursive; skip if same versionId installed; store `requiredDependencies`. Folders: `mods, shaderpacks, resourcepacks, datapacks`. Uninstall returns `{blocked,dependents}` (not an error). Toggle = `.disabled` suffix with ordering (enable requirements first, disable dependents last). Exact `versionId` pins mean same project id is not enough. `.mrpack`: index <=4MB, <=50k entries, `env.client != unsupported`, 8 concurrent hash-checked, extract `overrides/` + `client-overrides/`.
- Performance mods: Sodium, Lithium, FerriteCore (Modrinth, fabric), 7-day cache `cache/performance-mods/<slug>-<mc>.json`, manifest `mods/.mangoclient-performance.json`. A user jar matching conflicts (sodium|embeddium|rubidium|optifine|vulkanmod|nvidium; lithium|canary; ferrite) wins. fabric/quilt only. Never throws.
- Local mods: reconcile `profile.mods` with `mods/` (`.jar`, `.jar.disabled`, skip own and perf-managed). Unknown jar = `{projectId:"local:<filename>", local:true}`. Metadata from fabric.mod.json (strip trailing commas), quilt.mod.json, mods.toml, mcmod.info, or filename. Icons PNG <=256KB to `cache/mod-icons/<sha1>.png`. Live jar wins over `.disabled` twin. Watch `mods/` (500ms debounce) only for selected/running profiles.
- MangoConfig inject: see CLAUDE.md contracts.
- Servers: SLP protocol 767, SRV `_minecraft._tcp` when no port, 9s timeout, MOTD flattened with `§x` stripped. Featured: VincentVanilla (`vincentvanilla.net`). `servers.dat` NBT (gzip or raw, modified UTF-8, preserve compound order and list element types), `.mangoclient-backup` sidecar, seed only when absent (featured first, name `§6★ §r<name>`).
- Skins: account URLs, else session server (`?unsigned=false`, base64 textures), else embedded Steve. Cache `cache/skins/<uuid>.json`; return cache immediately then push update. Upload multipart classic|slim.
- Screenshots/logs: basename-only ids, inside-instances check; logs read last 4MB (gz streamed), `latest.log` first and undeletable; `crash:`/`game:`/`launcher:` prefixes.
- Storage: sections instances (never clearable), versions, libraries, assets, runtimes, natives, cache, logs; clear refused while a game runs.
- Updater: checks at launch (applies and relaunches ~800ms after download) and every 3h (offer only); enabled on Linux only inside AppImage; install on quit.

## IPC surface to reproduce as typed Tauri commands

`app:state, config:set, app:openFolder, app:openContentFolder, update:{state,check,install}, auth:{signIn,addOffline,remove,select,refresh}, skin:{get,default,upload}, profile:{list,create,update,delete,select,duplicate,covers,cover,pickCover,clearCover}, versions:manifest, loaders:versions, java:{list,pick,install}, game:{launch,stop,running}, mods:sync, modrinth:{search,project,versions,categories,install,uninstall,toggle,checkUpdates,checkAllUpdates,installModpack}, mangoconfig:info, shots:*, logs:*, stats:summary, storage:{usage,clear}, servers:{partners,ping,pingAll}`.
Events: `launch:progress, launch:log, launch:state, skin:updated, update:state, servers:pinged, mods:changed`. Replace the `{ok,data|error,needsRelogin}` envelope with `Result<T, AppError>` carrying a stable error code and `needs_relogin`.
Image protocol `mangoimg://cover/<uuid>` and `f/<base64url path>`: serve only image extensions whose realpath is under covers, `cache/mod-icons`, or a profile's `screenshots` dir.

## Gotchas

- `modrinth:toggle` throws when dependency metadata is incomplete; `skin:get` serves cache then pushes; `servers:pingAll` returns immediately and streams; Content-Length 0 from the Mojang CDN is non-authoritative; `VERSION_RE = ^[0-9A-Za-z][0-9A-Za-z._+-]{0,63}$`; numeric-aware version sorting; stats buckets use local midnight; single-instance lock.
- Windows ARM natives must not overwrite x64 DLLs.
- WebKitGTK/WKWebView are not Chromium: `tools/drive.js` (CDP) will not work for UI automation; plan Playwright/tauri-driver instead.
